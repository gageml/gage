---
title: Take up work from another session
description:
  How to start a new session that reads an earlier session and continues one
  task from it
---

A session takes on new tasks as it goes. You can finish each task where it
came up, or you can take one up in a new session. The new session reads the
earlier session through Gage and continues the task you name.

The new session reads only what concerns that task. Its context starts with
the current state of one piece of work, without the rest of the earlier
conversation. This lets you run each piece of work in its own session, with no
setup and no fork feature.

## Before you start

Install Gage and run `gage init`. See [Quick start](/start).

## Steps

1. Open a new session in the same project. Leave the earlier session as it is.

2. Tell the new session which session to read and which task to take up.

   ```text
   Look at the session titled "How-to section stubbing". Part of it deals
   with recording an animated GIF of a terminal session. We are taking up
   that work here.
   ```

   Your agent finds the session, reads the part about the task, and tells you
   where the work stands.

3. Continue the task in the new session. Return to the earlier session for the
   work that remains there.
