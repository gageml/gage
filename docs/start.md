---
title: Quick start
---

:::note

Gage is in early and active development. To provide feedback or PRs, visit our
[GitHub project](https://github.com/gageml/gage).

:::

Install Gage:

```shell
curl https://raw.githubusercontent.com/gageml/gage/refs/heads/release/scripts/install.sh | sh
```

Initialize the Claude Code plugin:

```shell
gage init
```

Run a scan:

```shell
gage scan
```

List open issues:

```shell
gage issue list
```

Resolve issues:

```shell
gage resolve
```

For steps to uninstall, see [_Uninstall Gage_](/docs/uninstall).
