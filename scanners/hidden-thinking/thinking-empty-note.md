Evidence of an empty thinking block

Thinking blocks provide valuable insight into model behavior. They should be
enabled to improve scan results. This note is written for the last thinking
block in a session at the time of writing. For the latest session and model, it
represents the strongest evidence for hidden thinking blocks.

**value** - `true` if the thinking block is hidden, otherwise `false`

**metadata**

- **msg_timestamp** - message timestamp, used to find the most recent thinking
  evidence
- **model** - the model the thinking block applies to
- **config** - the applicable `showThinkingSummaries` setting at the time of
  note writing (current config may differ)
