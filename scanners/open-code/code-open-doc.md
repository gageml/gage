Open code from error analysis

A brief, unstructured observation of something wrong or surprising in a
session, written by an annotator reading that session. The value is the
observation. The target is the session, optionally narrowed to a line
anchoring where the observed failure first shows.

Open codes are the raw input to axial coding: clustering observations across
sessions into recurring failure modes. Agent-written open codes carry a
scan-qualified author (`agent:open-code:{scan}`), so each annotation run is an
independent annotator.
