Evidence of an empty thinking block

Thinking blocks provide valuable insight into model behavior. They should be
enabled to improve scan results. This note is written for the last thinking
block in a session at the time of writing. For the latest session and model, it
represent the strongest evidence for hidden thinking blocks.

**value** - `true` if the thinking block are hidden, otherwise `false`

**metadata**

- **timestamp** - msg timestamp, used to find the most recent thinking evidence
- **model** - the model the thinking block applies to
- **config** is the applicable session project config at the tiem of note
  writing (current project config may differ)
