Summary of the Gage errors in a session

One note per session, written by an agent that read that session alone. The
value lists each error the session met while using Gage: a call to a Gage tool
that failed, a `gage` command that failed, and a Gage call that returned a
result the session had to retry or correct. Each entry gives the session line,
the call, the error text, and what the session did next. The target is the
session. `lines` metadata gives the session lines of the errors.

A session that used Gage without error has no note. The writer reports what
the session shows and does not judge whether Gage or the caller is at fault.
