Leave out what is not necessary to show what happened in the session.
Entries the harness wrote for its own record keeping are left out whole:
file snapshots, progress and permission records, API request records,
attachments, hook and skill listings, the system entries the conversation
does not show, and a user entry the harness injected as meta. On the
entries that stay, the fields that describe the run rather than what
happened are left out: the Claude Code version and entry point, the user
type, the slug, the permission mode, the effort and requested model, the
thinking duration, the API request id, the block index, and the token
usage. Entries and fields are selected by type, so there is nothing for a
model to judge.
