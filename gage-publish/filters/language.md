Remove language that is not fit for a public record: profanity, slurs,
sexual content, and abuse directed at a person or at the agent. A redaction
is a literal term matched everywhere, so judge each term, not each
occurrence: a term is removed wherever it appears or left everywhere. A term
the user wrote in an outburst is removed. A term that appears only inside a
document the user pasted as part of a discussion, or inside code or output
the user did not write, is left in place; a term that appears in both is
removed everywhere. Assistant output stays verbatim unless it repeats a term
the user wrote. Redact each term as a text redaction with reason "language":
without a marker when the sentence reads the same without the term, with a
marker when its absence would be noticed. Candid material that is not
profanity, such as venting about a colleague, takes reason "privacy".
